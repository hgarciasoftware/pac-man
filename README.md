## How do I run this code locally?

1. From the command line, run a local HTTP server from the root of this project's directory.
2. Then, access `index.html` on your browser at `localhost:[PORT]`.

Learn more about local testing servers here: https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Tools_and_setup/set_up_a_local_testing_server

I personally use `npx http-server`, which serves on port 8080 by default (More info: https://github.com/http-party/http-server#running-on-demand)
